# Getting Started - Simple

Simple Mode is the guided path for first-time users and solo developers.

## Install

Clone the repo and confirm Go is installed.

## First Run

```bash
go run . setup
go run . launch
```

## What Happens

1. Aeroform checks whether Ollama is installed.
2. Aeroform asks what you want to launch.
3. Aeroform shows a cost estimate.
4. Aeroform applies guardrails and records the tracked project locally.
