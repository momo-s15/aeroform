# Template Reference

This page tracks the template library by mode and cloud.

## Simple Mode

- AWS: static-site, contact-form, lambda-api, tiny-db, discord-bot, game-server, fullstack-app
- Azure: static-site, function-api
- GCP: static-site, cloud-run-api

## Pro Mode

- AWS: vpc, eks, rds-private, alb, lambda-api, ecs-fargate, cloudfront-api
- Azure: vnet, aks, cosmos-db, storage, app-service, key-vault
- GCP: vpc, gke, cloudsql, gcs
